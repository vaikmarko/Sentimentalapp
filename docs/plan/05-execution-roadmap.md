# 05 — Execution Roadmap

> Phases are gated by acceptance criteria, not calendar dates. Each phase ends with
> something a real user can touch. Workstreams within a phase can run in parallel
> (separate agents/branches — prompts for each in 06).

## Phase 0 — Foundation

Goal: new stack stood up, deployable, with auth — zero product features yet.

Workstreams:
- **F0.1 Web skeleton**: `/web` Vite+React+TS+Tailwind PWA scaffold; design tokens
  from 02 (colors, type, motion primitives); app shell with 5-tab navigation;
  Firebase Auth integration; capabilities layer interfaces (mic/push/share) with
  web implementations.
- **F0.2 API skeleton**: `/api` FastAPI on Cloud Run; Firebase Auth token middleware;
  Firestore + Storage clients; health/version endpoints; Cloud Tasks wiring with a
  demo async job; Sentry.
- **F0.3 CI/CD**: GitHub Actions — typecheck/lint/test gates, preview deploys,
  production deploy on main; bundle-size budget check.
- **F0.4 Legacy freeze**: move legacy app to `/legacy`, document its routes, keep it
  deployed and untouched.

Acceptance: a logged-in user loads the new empty app shell from production URL;
an async demo job round-trips through Cloud Tasks; CI green.

## Phase 1 — The Core Loop (Story)

Goal: speak → story, end to end, beautiful. This phase decides everything.

Workstreams:
- **P1.1 Speak**: recording screen per 02 (waveform, auto-stop, typing fallback);
  chunked upload to Storage.
- **P1.2 Distill pipeline**: transcribe → story extraction → title + emotional
  signature; prompt suite with golden tests (06); pipeline-run infrastructure from 03.
- **P1.3 Reveal + Chronicle**: story card UI, reveal animation, Keep action,
  Chronicle timeline, cover image generation.
- **P1.4 Daily prompt engine v1**: hand-curated universal prompts + context-aware
  selection once user has ≥3 entries; "Tonight" home screen.

Acceptance: time-to-magic < 90s for a new user; story keep-rate measurable;
founder uses it daily and the outputs feel true (no invented details) — this is a
hard gate; we do not proceed to media formats on top of a mediocre story engine.

## Phase 2 — First Media Artifact (Song) + Share

Goal: the first share-grade artifact and the public surface for it.

Workstreams:
- **P2.1 Song pipeline** (cost ladder per doc 07): lyrics+style generation +
  "Studio queue" admin screen for concierge generation through the founder's Suno
  account (Rung 1, ~€0) + provider interface with a MiniMax-via-fal.ai
  implementation behind a flag (Rung 2, ~$0.04/song); "in the studio" async UX +
  push on completion. Suno-wrapper premium tier deferred to Phase 5.
- **P2.2 Artifact player**: unified player, lyric sync, replay.
- **P2.3 Share pages**: server-rendered `/s/**` templates (story + song), OG tags,
  watermark, end-hook + try-widget v1 (record in page, story preview, signup to keep).
- **P2.4 Format recommendation v1**: rule-based mapping from emotional signature →
  recommended format; "more formats" drawer.

Acceptance: a song shared to WhatsApp unfurls richly, plays on the share page, and
the view→try→signup funnel reports data. Cost per song logged and within budget.

## Phase 3 — Gifting + Memory Film

Goal: both remaining hero mechanics, in conviction order.

Workstreams:
- **P3.1 Gift flow**: full flow from 02 (recipient → memory prompt → speak →
  format → preview → send); gift pages with unwrap animation; recipient
  zero-signup experience; reply-with-a-gift conversion.
- **P3.2 Memory Film pipeline**: script → ElevenLabs VO → Higgsfield visuals →
  ffmpeg assembly; photo-spark variant (user photo as image-to-video seed).
- **P3.3 Weekly Episode**: Cloud Scheduler cron → film pipeline over the week's
  stories; push delivery; episode player.

Acceptance: a complete gift can be created in < 3 minutes; a memory film from a
user photo is share-grade; weekly episode generates automatically for eligible users.

## Phase 4 — Distribution Surfaces

Goal: the outside of the product matches the reference-level craft bar.

Workstreams:
- **P4.1 Landing page**: video-backed cinematic page per 02, with live demo widget;
  the background film is generated by our own pipeline.
- **P4.2 Capacitor shell**: App Store / Play Store build of the same web app; push
  notifications, native share sheet, haptics; store assets.
- **P4.3 Wrapped v1 (monthly)**: swipe-through sequence + exportable 9:16 cards.
- **P4.4 Resonance feed v1**: anonymous publishing, "me too", "tell your version".

Acceptance: store builds approved; landing page converts measurably from share-page
traffic; first monthly Wrapped delivered to active users.

## Phase 5 — Iterate on evidence

Backlog seeded by data, not opinions: duet stories, fairytale gift variant,
voice-cloned narration (consent flow), yearly Wrapped film, paid tier activation,
embeddings-based context retrieval, occasion reminders, **Polished Note**
(voice-message polishing in the user's real voice via timestamp-cut editing —
concept in 01; hypothesis: a DM-native artifact with person-to-person
distribution lifts new-user acquisition without touching the core loop),
**The Listener** (guided voice capture on GPT-Live once its API ships —
concept and boundaries in 01; hypothesis: guided entries run longer and
yield higher keep-rate stories than one-shot voice notes).
Each item enters a phase only with a metric hypothesis attached.

## Cross-cutting tracks (run through all phases)

- **Prompt quality**: every generation prompt versioned + golden-tested; founder
  reviews tone drift on each change (process in 06).
- **Metrics**: the 04 dashboard grows with each phase; no feature ships without
  its funnel events. From Phase 1, log entry time-of-day to validate (or kill)
  the evening-usage hypothesis behind the "Tonight" framing and push timing
  (see 02).
- **Safety**: crisis-language detection from Phase 1; privacy copy reviewed
  per surface; GDPR data export/delete by end of Phase 2 (EU launch market).
- **Cost**: per-artifact cost tracking from the first Suno call; budget alarms.

## Sequencing rationale

Story before Song (a bad story makes an expensive bad song); Song before Film
(cheaper, faster pipeline to debug async UX on); Gifting before Wrapped (gifting
is conviction #1 and needs no installed base, Wrapped needs accumulated entries);
Capacitor after the loop is proven in PWA (no store-review tax on iteration);
Resonance feed last among product surfaces (needs artifact liquidity to not feel
empty).
